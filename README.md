# AVALON 3D World Prototype

Experimental 3D world combining creatures, environments, characters, audio and visual systems.

## Overview

11 Creatures (+1)  
8 Flora Assets  
16 Structures  
4 Characters (Rigged)  
4 Ambient Audio  
5 Tracks  
1 Font (Symbolic Script)
